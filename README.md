# Christianosity

*Familia Ante Omnia — Family Above All*

Christianosity is a religion founded on February 12, 2012, that places family first and loved ones second. Its core beliefs include unconditional love, loyalty, sacrifice, personal autonomy, hard work, and the relentless pursuit of a better life for those we love.
